# 仕様書：gh-lg-search（言語の惑星系）

## 1. 目的

GitHub ユーザーの公開リポジトリを「言語＝恒星、リポジトリ＝惑星」として描き、
**どの言語が中心か**と**どれだけ幅広い言語に触れてきたか**を一目で伝える。
旧版の円グラフと同じ情報を、見て楽しい表現に置き換える。

## 2. スコープ

### MVP（今回）
- ユーザー名を入力して検索 → 惑星系を表示
- 集計は旧版と同じ「リポジトリ数ベース」（各リポジトリの主要言語 `language` を1件として数える）
- 未認証の GitHub REST API のみ使用
- GitHub Pages で公開（静的ファイルのみ）

### 将来（今回は作らないが、設計で妨げないこと）
- PAT 入力 + GraphQL API による**バイト数ベース**の集計
- 時系列の詳細表示（年ごとの推移）
- 取得結果のキャッシュ（IndexedDB）
- 画像として保存・共有

## 3. データ取得と集計

| 項目 | 仕様 |
|---|---|
| ユーザー情報 | `GET https://api.github.com/users/{user}`（アバター、名前、bio、`public_repos`） |
| リポジトリ | `GET https://api.github.com/users/{user}/repos?per_page=100&page={n}`（`public_repos` から必要ページ数を計算し、全ページ取得） |
| 除外 | `fork == true` のリポジトリ、`language == null` のリポジトリ |
| 集計 | 言語ごとのリポジトリ数。並び順は件数の降順、同数なら言語名の昇順 |
| 時間軸 | `created_at` の年を使う |
| 言語色 | GitHub Linguist の `languages.yml` の `color`。色がない言語は `#cccccc` |

### エラー時の表示
| 状況 | 判定 | 表示 |
|---|---|---|
| ユーザーがいない | 404 | 「ユーザー {user} が見つかりません」 |
| レート制限 | 403 かつ `x-ratelimit-remaining: 0` | 「GitHub API の利用上限に達しました。{reset 時刻} 以降にもう一度お試しください」 |
| 対象リポジトリなし | 集計結果が空 | 「言語が判定された公開リポジトリがありません」 |
| 通信エラー | fetch 失敗 | 「通信に失敗しました。接続を確認してもう一度お試しください」 |

ローディング中は入力と検索ボタンを無効にする（旧版はエラー時にローディングが閉じなかった。同じ不具合を作らない）。

## 4. 画面構成

```
┌──────────────────────────────────────────────┐
│ [ユーザー名を入力        ] [検索]              │
├──────────────────────────────────────────────┤
│ アバター 名前 / login / bio                    │
├──────────────────────────────────────────────┤
│                                              │
│            惑星系キャンバス（16:10）             │
│                                              │
│ 51 repos                                     │
└──────────────────────────────────────────────┘
```

- URL クエリ `?user=xxx` で直接開ける。検索したら URL も更新する（`history.replaceState`）。
- キャンバスは 16:10 のまま、スクロールなしで画面に収まる最大の大きさで表示する。

## 5. 惑星系の描き方（見た目の仕様）

正解は `reference/prototype.html` の「案 B」。数式は `reference/prototype-planets.js` を参照。

| 要素 | 仕様 |
|---|---|
| 恒星 | 言語ごとに1つ。半径 `r = (3 + sqrt(n) × 2.6) × s`（`s` = キャンバス幅 / 640 × 拡大率。拡大率は §6）。言語色の放射グラデーションで光らせ、中心に白い核 |
| 惑星 | リポジトリごとに1つ。半径 `3 × s`。言語色 |
| 軌道 | 恒星を中心とした楕円（縦横比 0.45）。恒星ごとに ±0.35rad の傾き。軌道線は `rgba(231,233,240,.2)` |
| 軌道の半径 | **内側ほど古いリポジトリ**（`created_at` の昇順に内側から並べる）。`orbit_k = r + 7s + k × step`。`step = clamp((min(w,h) × 0.35 − r − 7s) / (n−1), 1.3s, 3.1s)` |
| 公転速度 | 角速度 ∝ `1 / sqrt(orbit / s)`（外側ほどゆっくり）。初期位相は乱数（シード固定） |
| 恒星の配置 | 惑星系同士が重ならないように自動配置（§6） |
| 言語名 | 恒星の下に表示（IBM Plex Mono 相当の等幅、`rgba(231,233,240,.6)`） |
| 背景 | `#0b0d14` |

### 表示
- 表示開始時からすべてのリポジトリの惑星を表示し、公転させる。年を追って増やす再生はしない。
- 左上に `{リポジトリの件数} repos` を表示する。
- 再生の操作UIは置かない。
- `prefers-reduced-motion: reduce` のときは公転も止め、静止画で表示する。

### インタラクション
- 惑星にホバー → `{リポジトリ名} · {言語} · {作成年}` のツールチップ。惑星を白い輪で強調
- 恒星にホバー → `{言語} · {件数} repos（{割合}%）`
- 惑星をクリック → そのリポジトリの GitHub ページを新しいタブで開く
- タッチ端末ではタップでツールチップを表示する

## 6. 恒星の自動配置

要件:
- 惑星系（外縁 `ext = 最外軌道 + 8s`）同士が重ならない
- 言語名ラベルがキャンバスからはみ出さない
- 下端の余白と左上の件数表示領域を避ける
- 同じ入力なら同じ配置（決定的）
- 惑星系が重ならずキャンバスに収まる範囲で、全体を最大 1.5 倍まで拡大する（1.5〜1.0 を 0.1 刻みで試す）
- 言語が 1〜25 個程度まで破綻しない

方式: プロトタイプは「大きい順に、既存の惑星系から最も離れた格子点に置く」貪欲法。
本実装では力学的配置（惑星系同士の反発 + 中心への弱い引力 + 枠からの反発を一定回数反復）に置き換えてよい。
どちらの場合も上の要件をテストで検証する。

## 7. 非機能要件

- GitHub Pages のサブパス（`https://f-a24.github.io/gh-lg-search/`）で動くこと
- 幅 375px のスマートフォンでも操作できること（キャンバスは幅いっぱい、16:10）
- 画面サイズが変わったら配置を計算し直す
- 惑星 500 個でも 60fps 近くで動くこと
