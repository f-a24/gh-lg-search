gh-lg-search / visual sketches

言語比率をどう見せるか、5つのスケッチ

表現案A〜Eを、Canvasで動くプロトタイプにしました。初期表示は f-a24 の実データ（51リポジトリ・12言語）です。AとBでは、玉や惑星にカーソルを合わせるとリポジトリ名が出ます。各ステージ右下の「もう一度」で、アニメーションを最初から再生できます。

案 A

落下する玉の瓶

リポジトリ1つが玉1つ。作成年の古い順に落ちて積もり、色の地層で比率と変遷が同時に見えます。

現在
玉の数＝リポジトリ数
バイト数
玉の大きさ
時系列
落下の順番と地層
相性：Leptos（rapier2dで物理演算）
案 B

言語の惑星系

言語が恒星、リポジトリはその周りを回る惑星です。年が進むごとに新しい惑星が生まれ、軌道に加わります。

現在
惑星の数
バイト数
恒星の大きさ・明るさ
時系列
惑星が生まれるタイミング
相性：MoonBit（計算が単純で自作しやすい）
案 C

フローフィールド

ノイズの流れに大量の粒子を流し、色の割合を言語の比率に合わせます。正確な数値よりも、その人の「色合い」を一枚の絵として見せる表現です。

現在
粒子の色の割合
バイト数
流れの太さ・粒子の量
時系列
縦軸を時間にとった流れ
相性：Leptos + wgpu（粒子数を増やすほど差が出る）
案 D

メタボール

言語ごとの液体の塊が、近づくと溶け合って色が混ざります。ピクセルごとの計算なので、本番ではシェーダーで描くのが向いています。

現在
塊の大きさ
バイト数
塊の面積
時系列
塊が膨らんでいくアニメーション
相性：Leptos + WGSL / MoonBit（WASMでピクセル計算）
案 E

成長する木

年が進むごとに枝が伸び、リポジトリが葉として芽吹きます。古い年の葉は内側に、新しい年の葉は外側に付きます。

現在
葉の数と色
バイト数
葉の大きさ
時系列
枝の伸びと葉が付く順番
相性：Gleam + p5.js（再帰をそのまま書ける）
実データは GitHub REST API（/users/f-a24/repos）から2026年11月5日に取得しました。集計方法は現行の gh-lg-search と同じく、各リポジトリの主要言語を1件として数えています（フォークと言語なしは除外）。架空のサンプルは54リポジトリ・2016〜2026年作成です。色はGitHub Linguistの言語色で、各スケッチは素のCanvas 2Dで描いています。
